Describing Appearance

Задания — Practice · 6 класс

1Fill in the Gaps (has / has got / is)

Заполни пропуски

Впиши правильную форму: has, has got или is.
1. My grandmother grey hair.
2. He very tall.
3. She blue eyes.
4. My brother a beard.
5. Our teacher short.
6. My friend freckles.
7. My dad bald.
8. She young.
9. My mum curly hair.
10. He a moustache.

3Game — Guess the Character!

Игра "Угадай персонажа"

Работайте в парах. Один ученик выбирает человека на картинке (молча, про себя). Второй ученик задаёт вопросы по-английски (только "yes/no" вопросы!), чтобы угадать, кого выбрал партнёр.

Key Questions to Ask (Ключевые вопросы)

  • Is this person a man / a woman? — Это мужчина / женщина?
  • Is this character tall / short? — Этот персонаж высокий / низкий?
  • Does this character have long / short hair? — У этого персонажа длинные / короткие волосы?
  • Does this character have curly / straight hair? — У него/неё кудрявые / прямые волосы?
  • Does this character have blonde / dark / red hair? — У него/неё светлые / тёмные / рыжие волосы?
  • Does this character have blue / brown / green eyes? — У него/неё голубые / карие / зелёные глаза?
  • Does this character wear glasses? — Он/она носит очки?
  • Does this character have a beard / a moustache? — У него борода / усы?
  • Does this character have freckles? — У него/неё есть веснушки?
  • Is this character young / middle-aged / elderly? — Этот персонаж молодой / средних лет / пожилой?
  • Is this character smiling? — Этот персонаж улыбается?
  • Is this character wearing something on their head? — На нём/ней что-то надето на голове?
